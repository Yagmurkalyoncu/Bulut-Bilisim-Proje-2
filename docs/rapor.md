3522 Bulut Bilişim Dersi - Proje 2 Raporu
Gerçek Zamanlı Veri Akışı ve İşleme (IoT Simülasyonu)
Hazırlayan:Yağmur Kalyoncu

1. Proje Hakkında
Bu projede, gerçek zamanlı veri akışının yönetilmesi ve bulut platformları üzerinde analiz edilmesi amaçlanmaktadır. Gerçek bir ortam bulma olasılığı kısıtlı olduğundan, Python dili kullanılarak bir IoT veri simülasyonu oluşturulmuştur.

2. Teknoloji Seçimi
Backend: Python (Boto3 kütüphanesi ile AWS entegrasyonu sağlanacaktır).

Bulut Platformu: AWS (Kinesis, Lambda ve DynamoDB tercih edilmiştir).

Protokol: MQTT/WebSocket yapısına uygun veri iletimi.

Veri Yapısı: Cihaz ID, sıcaklık, nem ve zaman damgası içeren JSON formatı.

3. Gelişim Günlüğü (Log)
Aşama 1: VS Code üzerinde çalışma ortamı hazırlandı ve proje klasör yapısı terminal komutlarıyla oluşturuldu.

Aşama 2: Sensör verilerini rastgele üreten Python simülasyon kodu yazıldı.

Aşama 3: Proje dokümantasyonu için Markdown formatında rapor dosyası oluşturuldu ve GitHub reposuna ilk gönderimler yapıldı.
